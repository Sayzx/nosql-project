🎯 RÉSULTATS CLÉS DE L'ANALYSE

4 Chemins d'attaque depuis PC-ALICE :

1. PC-ALICE → SRV-WEB
   - Vulnérabilité : Log4Shell (CVE-2021-44228, score 10.0 RCE)
   - Impact : Compromission serveur web

2. PC-ALICE → SRV-WEB → SRV-DB
   - Vulnérabilité : MySQL Auth Bypass (CVE-2020-14625, score 8.5)
   - Impact : Accès données clients et secrets applicatifs

3. PC-ALICE → SRV-WEB → SRV-DB → DC-01
   - Vulnérabilité : Zerologon (CVE-2020-1472, score 10.0 RCE)
   - Impact : Compromission complète du domaine

4. PC-ALICE → SRV-WEB → SRV-DB → DC-01 → NAS-BACKUP
   - Vulnérabilité : SMBv1 RCE (CVE-2017-0144, score 9.8)
   - Impact : Perte des sauvegardes

Durée estimation d'exploitation complète : < 2 heures
